 Quiz App

A full-stack Quiz Application built with **Angular**, **Node.js**, and **MongoDB**.  
Users can **create** and **practice** quizzes by category such as *Angular*, *DSA*, and more.

---

 🚀 Features

- User Authentication (Login / Logout)
- Dashboard with quiz categories
- Create quizzes dynamically per category
- Practice quizzes from the database
- RESTful backend API using Node.js + Express
- MongoDB for quiz storage
- Responsive and modern UI using Angular standalone components
